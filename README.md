# UMLith — UML to Java

Interactive React-based UML Class Diagram Generator.

## Features
- Add/edit Class and Interface nodes
- UML attributes and methods
- Method parameters
- Association, inheritance, implementation, aggregation and composition
- Multiplicity and relationship labels
- Automatic Java source generation
- Multiple generated `.java` views
- Copy/download Java code
- Save/load with localStorage
- JSON export/import
- Responsive animated UI
- Student header/footer: Vaishnavi Narkhede | Rollno: 48

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
